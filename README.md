# Off Route Presents

A website prototype for an electronic music events and artist management company.

Run `node build.mjs` to generate the site in `dist/`, then serve it with `python3 -m http.server 8000 --directory dist`. Netlify uses the same build command and publish directory.

- `Resources/Brand/` holds the original supplied PNGs.
- `Resources/Placeholders/` holds the AI-generated website artwork for the prototype.
- The site uses sample visuals and editorial material while approved show details, artist profiles, and copy are being prepared. The Posts page structure is ready for the planned Notion CMS connection.
